

# jck-pro-max

## 简介

`jck-pro-max` 是一款功能强大的 Android 设备综合管理与系统深度工具箱。该应用不仅提供了应用商店功能（搜索、安装、收藏管理），还包含针对特定固件环境（Zybos）的底层系统服务调用与调试能力，适用于设备信息查询、应用管理及系统级参数篡改。

## 主要功能

### 1. 应用商店 (Store)
*   **智能搜索与浏览**: 支持关键词搜索应用，并提供分类筛选（如推荐、历史记录）。
*   **高效安装**: 支持单个应用安装与批量选中安装模式。
*   **个性化收藏**: 可收藏喜爱的应用，并查看最近浏览记录。
*   **缓存机制**: 具备本地应用数据缓存功能，提升加载速度。

### 2. 应用启动器 (App Launcher)
*   **全应用管理**: 展示设备内所有应用，并支持按系统/非系统应用进行筛选。
*   **高级启动**: 支持查看应用详情、复制包名、以及以“清除任务栈”的方式启动应用，便于多任务管理。

### 3. 设备工具 (Device Tools)
*   **信息查询**: 提供设备序列号 (SN)、子设备 ID 的查询与绑定。
*   **行为数据**: 支持获取设备使用行为历史 (Behavior History)、屏幕使用时长 (Using Time) 以及 Pisou 历史记录 (Pisou History)。

### 4. Zybos 系统工具 (Zybos Tools - 核心模块)
该模块封装了大量针对系统底层服务的高级调用接口（通常需要 Root 权限或特定系统环境支持）：
*   **系统服务漏洞利用 (VulnHelper)**: 包含对 DuraSpeed (进程管理), MtkPpl (性能/电源管理), DataShaping (流量整形), PowerHal (硬件性能调控) 等服务的探测与控制。
*   **家长控制管理**: 提供禁用家长控制、解除隐私锁 (Privacy Lock)、取消系统更新等强力功能。
*   **系统属性 (SysProp) 与设置 (Settings)**: 支持通过 Root 读写系统属性，修改网络配置（如 DNS），以及调整 ADB 开关、显示参数等。
*   **硬件与电量**: 支持查询充电器状态、电池健康度、硬件组件信息，并可进行 PQ/Gamma 屏幕参数调节。
*   **系统服务调用**: 支持通过 Transaction 直接调用系统隐藏 API，执行如强制停止应用、恢复出厂设置前的准备操作等。

### 5. 辅助功能
*   **广播安装 (Broadcast Install)**: 支持通过广播 (Broadcast) 发送安装指令，适用于自动化部署或系统级应用推送。
*   **终端日志 (Terminal)**: 提供应用运行日志的实时查看功能。
*   **更新机制**: 内置应用自身更新检查与下载安装功能。

## 技术架构

*   **开发语言**: Java (Android Native)
*   **核心组件**:
    *   `com.jck.promax.StoreActivity`: 负责应用商店逻辑，包含复杂的网络请求与 UI 渲染。
    *   `com.jck.promax.ZybosToolsActivity` & `ZybosVulnHelper`: 实现了对系统隐藏服务与底层硬件的反射调用及漏洞利用逻辑。
    *   `com.jck.promax.ApiHelper`: 封装了与后端 API 的通信逻辑，包含请求签名、MD5 校验以及 AES 数据加解密。
    *   `com.jck.promax.Obfuscator`: 用于字符串解密和代码混淆处理，增强安全性。

## 依赖与构建

1.  **环境**: 需要 Android Studio 或 Gradle 构建环境。
2.  **SDK**: 基于 Android SDK 开发。
3.  **权限**: 应用声明了联网、存储读写、设备信息访问等权限。**注意：部分高级系统工具功能需要设备已获取 Root 权限才能正常运行。**

## 使用说明

1.  **安装**: 将编译好的 APK 文件安装到 Android 设备上。
2.  **启动**: 打开应用，首次启动可能会展示免责声明。
3.  **操作**:
    *   **商店**: 在 Store 界面搜索并安装应用。
    *   **工具**: 进入 Device Tools 或 Zybos Tools 进行设备调试。
    *   **启动器**: 在 App Launcher 中管理本地应用。

> **警告**: 本应用包含大量底层系统修改功能（如禁用家长控制、修改系统属性等）。请务必在了解操作后果的情况下使用，误操作可能导致系统不稳定或功能异常。
